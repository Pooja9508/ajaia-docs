## Local Setup

### Requirements
- Python 3.10+
- pip

### Steps

```bash
# 1. Clone / unzip and enter the directory
cd ajaia-docs

# 2. Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. (Optional) copy .env.example to .env and customise
cp .env.example .env

# 5. Start the server
uvicorn main:app --reload

# 6. Open in browser
open http://localhost:8000
```

The database is auto-created at `ajaia_docs.db` on first boot.  
Demo users (alice, bob, carol) are seeded automatically if the database is empty.

### Database migration (existing installs only)

If you have an `ajaia_docs.db` from a previous version, run the one-time migration to add new columns:

```bash
python migrate.py
```

### Run tests

```bash
pytest tests/ -v
```

All 18 integration tests should pass.

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `SECRET_KEY` | _(random, unstable)_ | JWT signing secret. Set in production for stable sessions. |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `480` | Token lifetime (8 hours) |
| `DATABASE_URL` | `sqlite:///./ajaia_docs.db` | SQLite locally, PostgreSQL on Render |
| `UPLOADS_DIR` | `uploads` | Directory for uploaded images and attachments |
| `SMTP_HOST` | _(optional)_ | SMTP server for email invitations |
| `SMTP_PORT` | `587` | SMTP port |
| `SMTP_USER` | _(optional)_ | SMTP username |
| `SMTP_PASS` | _(optional)_ | SMTP password |
| `SMTP_FROM` | `noreply@ajaia-docs.com` | From address for emails |
| `APP_URL` | `http://localhost:8000/` | Base URL for invitation links |

Email features (invitations, access request notifications) work without SMTP configured — the app falls back gracefully and shows the invite link directly in the UI.

## Deployment (Render.com — free tier)

1. Push repo to GitHub (public or private)
2. Go to [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint**
3. Connect your GitHub repo — Render reads `render.yaml` automatically
4. Click **Apply** and wait ~2 minutes for the first deploy
5. Render provisions a free PostgreSQL database and injects `DATABASE_URL` automatically
6. `SECRET_KEY` is auto-generated by Render

> **Note on free tier:** Render's free web service spins down after 15 minutes of inactivity (cold start ~30 s). Uploaded files are ephemeral on free tier — for production use S3/R2.
